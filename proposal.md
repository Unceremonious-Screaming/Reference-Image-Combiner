# Reference Image Combiner

## Repository
<[Link to project's GitHub respository](https://github.com/Unceremonious-Screaming/Reference-Image-Combiner)>

## Description
My project will generate one PNG file out of multiple given images, combining them in an organized way so that every image can be referenced from one file. This will be useful for creating a single file that can be referenced for a character design, mood boards, concept ideas, etc, so that the user won't have to make one manually for their creative projects.

## Features
- Combine images
	- It will combine images by adding them together along their sides.
- Organize images
	- It will organize images by size of width/height, minimizing empty space as much as possible.
- Randomize organization
	- It will allow the user to randomize the organization of the images in the final file, if the organization is not to their liking the first time.

## Challenges
- I will need to learn how to get the images to organize in an ideal way based on their size; I need to figure out how to tell the code to put an image in a certain spot based on the sizes of other images.
- Randomization of the organization may be difficult due to similar reasons as mentioned above; I need to learn how to get the code to reorganized in an optimal way in multiple different orientations.
- I may need to learn how to get the code to process images that are not perfectly square.

## Outcomes
Ideal Outcome:
- The project will be able to combine and align all given images while minimizing space, preferably in a near-square rectangle shape. The user will be able to randomize the orientation.

Minimal Viable Outcome:
- The project will be able to combine all images, although there may be a lot of gaps in space, and the final image may be too long or tall in shape. The user may not be able to randomize the final image outcome.

## Milestones

- Week 1
  1. All images will be able to combine together into one PNG file.
  2. The images will be organized in roughly a square shape.

- Week 2
  1. The code will process all images to organize them in a way to minimize blank space.

- Week N (Final)
  1. The final image can be randomized, allowing for the images to be placed in different spots.
  2. The randomized image will still minimize blank space, and stay in roughly a square shape.
  3. The code functions at least at the minimal viable outcome.
